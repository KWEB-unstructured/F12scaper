# 호환성 점검표

담당: 김씨. 출시 전과 큰 변경 뒤에 한 번씩 돈다. 자동 점검은 Claude 가 브라우저 자동 실행으로 돌린 결과, 수동 점검은 사람이 직접 확인할 항목이다.

## 1. 자동 점검 결과 (2026-11-26, Production `f12scaper.vercel.app`)

| 항목 | 방법 | 결과 |
|---|---|---|
| 광고 차단 — 요청 | EasyList · EasyPrivacy · uBlock 기본 목록(filters·privacy·badware·unbreak) · Peter Lowe · AdGuard Korean 에 실제 요청 주소를 대조. `/api/start` `/api/stage5` `/api/ranking` `/api/verify` `/system/terminate`, 번들 JS·CSS, `/stages/stage7-flash.js`, `/prologue/library-bg.png` | **막히는 요청 0개** |

| 엣지 최신 | 1~8단계 화면 + 광고 차단 대조, 8단계 콘솔 탈출 전체 흐름 (로컬 mock 서버) | 통과 |
| 시크릿 모드 | 자동 실행 브라우저는 매번 빈 프로필(시크릿과 같은 조건)이라 위 결과가 곧 시크릿 결과. localStorage·sessionStorage·같은 출처 쿠키(4단계) 모두 동작 | 통과 |

## 2. 수동 점검 (출시 전 1회)

환경마다 1~8단계를 처음부터 끝까지 한 판. 문제가 있으면 칸에 적는다.

| 단계 | 확인할 것 | 크롬 | 엣지 | 크롬 + uBlock Origin | 크롬 + AdBlock | 시크릿 |
|---|---|---|---|---|---|---|
| 프롤로그 | F12 를 누르면 갇히는 연출, 콘솔 메시지 | | | | | |
| 1 | Elements 에서 HTML 주석이 보인다 | | | | | |
| 2 | Styles 에서 `display: none` 을 지우면 버튼이 나온다 | | | | | |
| 3 | 콘솔에서 `unlock("…")` 실행. 처음 붙여 넣을 때 `allow pasting` 경고가 뜬다 (크롬·엣지 둘 다) | | | | | |
| 4 | Application → Cookies 에서 `role` 을 `admin` 으로 → 새로고침 → 반전 장면 | | | | | |
| 5 | 버튼 → Network 에 빨간 `stage5` (403). Headers 의 `X-Archive-Key`, Response 의 `key_tail`·`maintenance` | | | | | |
| 6 | 기기 모드(크롬·엣지 모두 `Ctrl+Shift+M`) 375px 에서만 보이는 문장 | | | | | |
| 7 | Sources 에서 `stages/stage7-flash.js` 에 중단점 | | | | | |
| 8 | 콘솔 `fetch('/system/terminate', …)` → 결말 → 클리어 → 랭킹에 내 기록 | | | | | |

환경별로 깨질 수 있는 지점
- **쿠키를 전부 막은 브라우저**(설정 → 쿠키 모두 차단): 4단계 쿠키 퍼즐과 localStorage(진행 저장)가 같이 막혀 게임이 진행되지 않는다. 시크릿 모드는 같은 출처 쿠키를 허용하므로 괜찮다.
- **개발자 도구가 회사·학교 정책으로 막힌 PC**: 게임 자체를 할 수 없다. 안내 대상 아님.
- **크롬·엣지 외 브라우저**(파이어폭스·사파리): 개발자 도구 화면이 달라 힌트 문구(탭 이름, 단축키)가 맞지 않는다. 기획대로 "크롬 권장"만 안내한다.

## 3. 문제가 생겼을 때 안내 문구를 어디에 띄울까 (제안)

자동 점검에서 광고 차단 문제는 없었다. 그래도 사용자 환경(다른 필터 목록, 보안 프로그램)은 모두 알 수 없으므로 **실패했을 때만** 안내한다. 처음부터 시작 화면에 띄우면 문제가 없는 대부분에게 불필요한 경고가 된다.

| 위치 | 언제 | 문구 예 | 담당 |
|---|---|---|---|
| 프롤로그 끝 "다시 시도" (`/api/start` 실패) | 서버 연결 실패가 반복될 때 | "계속 실패하면 광고 차단 확장을 끄거나 시크릿 창에서 열어 주세요." | 정씨(화면) · 형씨(문구) |
| 5단계 | 버튼을 눌러도 Network 에 `stage5` 가 안 보일 때는 화면이 알 수 없으므로, 힌트 2 끝에 한 줄 | "Network 탭에 아무것도 안 보이면 광고 차단을 끄고 다시 눌러 봐." | 김씨 |
| 8단계 `SERVER_DOWN` | 응답이 없을 때 | 위와 같은 안내 | 정씨 · 형씨 |

## 4. 결정이 필요한 것: 소스맵

`vite.config.js` 는 "플레이어가 Sources 탭에서 원본 코드를 읽을 수 있게" 소스맵을 같이 빌드한다. 그런데 **Vercel 이 Production 의 `.map` 파일을 403 으로 막고 있다** (`/assets/index-*.js.map` → 403).

- 퍼즐에는 영향 없다. Sources 에서 읽어야 하는 7단계 코드는 `public/stages/` 에 따로 있어서 소스맵이 필요 없다 (CLAUDE.md 규칙 2).
- 대신 개발자 도구가 소스맵을 받으려다 실패해서 **콘솔에 "DevTools failed to load source map" 경고가 뜰 수 있다.** 콘솔이 이야기의 주 무대인 게임이라 거슬릴 수 있다.

| 선택 | 방법 | 결과 |
|---|---|---|
| A. 소스맵 끄기 (추천) | `vite.config.js` 의 `sourcemap: true` → `false` | 콘솔 경고 없음. 번들은 압축된 채로 보인다 (원래도 403 이라 지금과 같다) |
| B. 공개하기 | Vercel 설정에서 소스맵 보호를 끄기 (계정·플랜에 따라 메뉴가 없을 수 있다) | 원래 의도대로 원본 코드가 보인다 |
| C. 그대로 | — | 경고가 뜨는지 수동 점검 때 확인하고 거슬리지 않으면 둔다 |
